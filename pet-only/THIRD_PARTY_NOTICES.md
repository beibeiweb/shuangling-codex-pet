# 纯宠物包来源与许可

本包包含霜铃图集、宠物描述、一键安装/卸载脚本与说明。未包含启动动画、语音、启动器或第三方运行时。

霜铃图集由本项目维护者选择用于分发；角色和图像不自动适用软件源码的 MIT 许可。抽取用于其他作品、商业用途或单独素材库前应核实相关素材许可。

参考 timerring/codex-pet-naiwa 的 v2 图集组织与轻量分发方式，未使用其角色图像。

本包需要用户已安装 Windows 和支持 sprite v2 的 Codex 桌面版。本项目与 OpenAI 无官方关联。
